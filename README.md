# Weather Normalization Action Game - Two-Stage Prototype

A dependency-free Canvas side-scrolling action prototype. Open `index.html` in a modern browser (or serve this directory with any static file server).

## Controls

- **← / →** move
- **Z** jump
- **X** cast wind (hold a direction, or use the facing direction)
- **Enter** start / retry

Choose **Fog Harbor** or **Thunder Plateau** with the arrow keys. Fog Harbor retains its fog-clearing and projectile-reflection route. In Thunder Plateau, Wind moves Charge Clouds—not lightning—so future strikes can be guided into Lightning Rods to open barriers and normalize the abnormal cumulonimbus.

All art has Canvas fallbacks, so both stages remain playable without optional files in `assets/cards` and `assets/monsters`.
