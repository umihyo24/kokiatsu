# Weather Normalization Action Game - Prototype 01: Fog

A dependency-free Canvas side-scrolling action prototype. Open `index.html` in a modern browser (or serve this directory with any static file server).

## Controls

- **← / →** move
- **Z** jump
- **X** cast wind (hold a direction, or use the facing direction)
- **Enter** start / retry

Clear fog from the boss core, then turn its own projectiles back on the exposed core four times to normalize the weather.
